# GeraKWonderAlice

> Серверная прослойка для умных колонок Яндекс Станция на базе Google Gemini API со снятыми ограничениями и быстрым откликом.

## Стек технологий
* **Платформа:** Яндекс Диалоги (приватный навык)
* **Среда выполнения:** Node.js / Vercel Serverless Functions
* **Ядро ИИ:** Google Gemini 2.5 Flash API

## Возможности
* **Без цензуры:** прямое общение без шаблонных заглушек и морализаторства
* **Скорость:** отклик за 1–2 секунды (укладывается в лимиты таймаута Алисы)
* **Память сессии:** удержание контекста текущего диалога
* **Голосовой формат:** очистка текста от Markdown, списков и спецсимволов для корректного TTS
